# Accessibility Rules (a11y)

- **Keyboard Traversal:** 100% of interactive controls (palette, tabs, review actions, teleop, sliders, playback) are navigable via keyboard with visible focus rings.
- **Screen Reader Announcements:** Log pane utilizes throttled polite ARIA live regions (`aria-live="polite"`).
- **Reduced Motion:** When `@media (prefers-reduced-motion: reduce)` is enabled, all non-essential UI animations, pulsing effects, and camera transitions are disabled.
- **Color Contrast & Dual Encoding:** Text meets WCAG AA contrast ($\ge 4.5:1$). Status indicators pair color with distinct icons and explicit textual labels.
