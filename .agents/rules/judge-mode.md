# Judge Mode Rules — 3-Minute Offline Scripted Tour

- **100% Offline Capability:** Judge Mode (`J` key) runs completely without network access, without cloud credentials, and without a webcam, utilizing pre-recorded landmark fixtures and local simulation.
- **Persistent Caption Bar:** A high-contrast caption bar is visible at all times, permanently carrying the label `"Scripted tour"` and explaining current step operations.
- **Full Playback Control:** Tour can be paused (`Space`), skipped to next step (`Right Arrow`), or exited cleanly (`Esc`).
- **Clean State Exit:** Exiting Judge Mode leaves zero dirty state, lingering workers, or modified user preferences.
